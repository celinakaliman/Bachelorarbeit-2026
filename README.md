##### The underlying dataset, the Default of Credit Card Clients dataset from the UCI Machine Learning Repository (Yeh, I. (2009). Default of Credit Card Clients [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C55S3H), is provided in the folder "data" under "credit_data.csv". It is recommended to locally store the dataset. If not, the dataset is fetched from the UCI repository when the first notebook is run.

##### This repository consists of two notebooks. Notebook 1 includes the data and model preparation. The output of Notebook 1 is saved to the folder "data/Output_Notebook1". The output saved in "data/Output_Notebook1" in then fetched when Notebook 2 is run. Notebook two includes the in- and postprocessing stages as well as the experiment results. The results of Notebook 2 are then saved to the folder "results" in the files "entire_results_table.xlsx" and "supporting_table_intersectional_groups.xlsx". The file "Appendix Tables Bachelors Thesis.xlsx" contains the prepared data tables provided in the Appendix of the Bachelor´s Thesis and was prepared in Excel.
